# QuoteAura – Random Quote Generator

## About the Project

QuoteAura is a Random Quote Generator developed using HTML, CSS, and JavaScript. It displays inspirational quotes in a modern and stylish interface.

## Features

* Displays a random quote when the app opens.
* Generates another quote using the New Quote button.
* Displays the quote and author's name.
* Copy quotes to the clipboard.
* Save favourite quotes.
* Stores favourite quotes using localStorage.
* Modern, responsive user interface.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
